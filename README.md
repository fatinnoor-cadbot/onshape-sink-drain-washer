# Sink Drain Washer | Onshape CAD Project

### 3D Modeling | Parametric Design | Mechanical Engineering

## 📌 Project Overview

This repository showcases my 3D CAD model of a sink drain washer, created using Onshape.

I completed this project as part of my CAD practice, following a tutorial by Too Tall Toby. The exercise helped me understand how a mechanical component can be developed from a 2D sketch into a finished 3D model.

## 🛠️ Tools & Software

- **Software:** Onshape
- **Modeling Method:** Parametric 3D Modeling
- **Project Type:** Mechanical Component Modeling
- **Learning Resource:** Too Tall Toby

## ⚙️ Modeling Process

- Created the initial 2D sketch.
- Applied dimensions to define the geometry.
- Used CAD features to develop the 3D washer.
- Examined the finished component from different perspectives.
